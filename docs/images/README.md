# App Mockups

These images show the current Training Log interface with synthetic workout data. The editable compositions are in [Figma](https://www.figma.com/design/kN2PWdpIGwS7ObCjENH3Ek?node-id=3906-374).

Device frames are adapted from the [iPhone 18 Pro Flat Mockups Community template](https://www.figma.com/community/file/1155100064547881598/iphone-18-pro-flat-mockups). The original template remains in the Figma file. App interface layers and captions are editable. The screen content uses Golos Text, matching the web client.

The hero shows workout planning, logging, and the muscle ledger. Individual exports add a larger view of each screen and the rest timer. All examples are illustrative, with no personal training records or authentication details.
